# Проверка публикации

16 ноября 2026 года выполнены следующие проверки:

- Опубликованные копии `train.py` и `predict.py` запущены в отдельной рабочей папке с копией локального датасета. Обучение прошло полностью за 5 эпох на CUDA, checkpoint сохранён и затем загружен для предсказания. Получены `Prediction: Ankle boot`, `Target: Ankle boot` для первого тестового изображения.
- Train loss проверочного запуска по эпохам: `0.54136896`, `0.35244861`, `0.30324363`, `0.26929891`, `0.24626106`. Это отдельный запуск для проверки кода, а не восстановленная история исходных весов. Инициализация модели не фиксировалась.
- `evaluate.py` отдельно оценил **исходный сохранённый пользовательский checkpoint**, а не новые веса проверочного запуска: validation accuracy `0.9044166666666666`, test accuracy `0.897`. Полные числа и оговорки сохранены в `reports/metrics.json`.
- Размер validation — 12 000, test — 10 000. Cross-entropy при оценке усреднена по изображениям; confusion matrix построена только по результатам полного test.
- Проверены синтаксис скриптов, соответствие исходной логики публикации рабочим файлам, загрузка checkpoint и размеры сети.
- Хеши исходных скриптов, checkpoint и файлов датасета до и после работы совпали. Рабочие веса не изменялись.
- Матрица ошибок построена по числам из JSON и просмотрена. Исходные картинки, датасет, веса, окружение и рабочие логи не публикуются.

Окружение: Windows, Python 3.13.2, PyTorch 2.10.0+cu126, torchvision 0.25.0+cu126; CUDA доступна. График построен с Matplotlib 3.10.3. Установка в полностью чистое окружение и повторная загрузка датасета из сети не проверялись — использовался уже скачанный локальный набор.

В исходной папке Git-истории не было. Репозиторий создан в отдельной подготовленной копии. Логика двух пользовательских скриптов сохранена; убраны только пробелы в концах строк. Код оценки добавлен отдельно.
